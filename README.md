# NovaMind AI — Marketing Site

Marketing site for NovaMind AI, a multi-channel eCommerce and AI growth agency.
Covers the twelve growth engines: Amazon, Walmart, eBay, TikTok Shop, Temu, Etsy
and Shopify marketplace management, plus AI agents, SEO, Meta & Google Ads,
Android apps and custom software.

## Stack

- **TanStack Start** (React 19) with file-based routing and SSR
- **Tailwind CSS v4** — theme tokens and custom utilities live in `src/styles.css`
- **shadcn/ui** components in `src/components/ui`
- **Nitro** build target

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
npm i
npm run dev
```

| Script | What it does |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run build:dev` | Build in development mode |
| `npm run preview` | Preview a production build |
| `npm run lint` | ESLint (includes Prettier rules) |
| `npm run format` | Format everything with Prettier |

## Layout

```
src/
  routes/          file-based routes — __root.tsx is the app shell
  components/site/ page sections: Header, Footer, services grid, motion helpers
  components/ui/   shadcn/ui primitives
  lib/             services content, utils, SSR error page
  assets/          hero and team imagery
  styles.css        design tokens, custom utilities, motion keyframes
public/            favicon, robots.txt
```

### Notes

- `src/routeTree.gen.ts` is generated by the router plugin — don't edit it by hand.
- Brand colours, gradients and the motion system are all defined as `@theme` /
  `@utility` blocks in `src/styles.css`; restyle there rather than in components.
- `src/server.ts` wraps the server entry to render a styled error page when SSR
  fails, instead of a bare 500.

## Content

Service copy, categories and metrics live in one place — `src/lib/services-data.ts`.
Page copy (stats, FAQs, testimonials, roadmap) is defined as constants at the top
of each file in `src/routes/`.
